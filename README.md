# School Website

## Description
A responsive school website developed using Vite, HTML, CSS, and JavaScript.
The website provides information about the school, academics, facilities,
admissions, events, and contact details through a simple and user-friendly interface.

## Technologies Used
- Vite
- HTML5
- CSS3
- JavaScript
- React

## Features
- Responsive design
- Home page
- About School section
- Academics section
- Admissions information
- Facilities section
- Events/News section
- Contact section
- Navigation menu
- Mobile-friendly layout

## Project Setup

### Install dependencies
npm install

### Run the development server
npm run dev

## Build for production
npm run build
